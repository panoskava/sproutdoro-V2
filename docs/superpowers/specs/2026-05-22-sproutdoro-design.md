## 1. Overview

**Sproutdoro** is a garden-themed Pomodoro timer web application. It transforms productivity sessions into a living digital garden — each completed focus session plants a new seedling that grows and matures based on accumulated focus time.

**Creative North Star:** "The Digital Greenhouse" — rejecting clinical productivity aesthetics in favor of cultivation, warmth, and organic growth.

**Key Differentiators:**
- Visual garden that grows as you focus
- Cottagecore aesthetic with earth-tone palette
- Gamified focus sessions with rarity-based plant collection
- Fully offline-capable PWA with local data persistence
- Multi-page architecture (not SPA) for simplicity and reliability

### 3.2 Navigation Pattern

Standard HTML `<a href="...">` links between pages. Each page includes:
- **SideNav** (desktop, left sidebar): User profile, nav links, "Start Session" button
- **MobileNav** (mobile, bottom): Icon buttons with labels, FAB center on index/garden

Active page is highlighted via CSS class applied server-side (or via JS reading `window.location`).

### 3.3 State Management

**Global State (pub/sub pattern):**
```typescript
interface AppState {
  currentScreen: 'focus' | 'settings' | 'insights' | 'garden';
  timer: {
    mode: 'work' | 'shortBreak' | 'longBreak';
    state: 'idle' | 'running' | 'paused' | 'complete';
    remainingSeconds: number;
    totalSeconds: number;
    sessionCount: number; // sessions completed this cycle
  };
  settings: Settings;
  garden: GardenState;
}
```

State changes emit events that components subscribe to. This avoids prop drilling across the multi-page app.

### 4.2 Session Store

```typescript
interface Session {
  id: string;                  // UUID
  startTime: number;           // Unix timestamp (ms)
  endTime: number;             // Unix timestamp (ms)
  duration: number;            // actual duration in minutes
```

### 4.3 Plant Store

```typescript

  level: PlantLevel;
  plantedAt: number;           // Unix timestamp (ms)

interface GardenState {
  plants: Plant[];
  totalPlants: number;
  totalFocusHours: number;
  unlockedTypes: string[];
  featuredPlantId: string | null;

```

### 4.4 Insights Store

```typescript

  name: string;
```

**Timer Logic:**
- On mount: Load settings from IndexedDB, set initial duration
- Countdown: `setInterval` every 1000ms, update `remainingSeconds`

- Sun dot: rotate around center based on progress percentage
- Completion: Play sound, save session, generate plant, show celebration modal
- Auto-transition: If `autoStartBreaks` enabled, start break timer after work completion
- Session cycle: Work → Short Break (×3) → Work → Long Break (after 4th work session)

**States:**
| State | Visual | Action Button |
|-------|--------|---------------|
| Idle | Full ring empty, time at full duration | "Start" (play icon) |
| Running | Ring filling, time counting down | "Pause" (pause icon) |
| Paused | Ring frozen | "Resume" (play icon) |
| Complete | Full ring, 00:00, celebration | "Start New" (play icon) |
| Break | Different color accent, shorter duration | Same as work states |

## 6. Gamification System

### 6.1 Plant Generation

**Trigger:** When a work session timer reaches 00:00 (completed).

**Process:**
1. Create new `Session` record with `completed: true`
2. Generate new `Plant`:
   - `id`: crypto.randomUUID()
   - `type`: Random from available types
   - `rarity`: Weighted random:
     - Common: 70%
     - Uncommon: 20%
     - Rare: 8%
     - Legendary: 2%
   - `level`: 1 (Sprout)
   - `plantedAt`: current timestamp
   - `totalFocusMinutes`: session duration
   - `sessionIds`: [session.id]
   - `isMasterpiece`: false (recalculated after insertion)
3. Recalculate `isMasterpiece` for all plants (highest `totalFocusMinutes` wins)
4. Update Insights (streak, daily stats, achievements)

### 6.2 Plant Leveling

Plants level up based on cumulative focus time:

| Level | Name | Focus Time | Visual |
|-------|------|-----------|--------|
| 1 | Sprout | 0-60 min | Tiny seedling |
| 2 | Growing | 60-180 min | Small plant |
| 3 | Thriving | 180-300 min | Medium, fuller |
| 4 | Mature | 300-480 min | Full size |
| 5 | Blooming | 480+ min | Flowering, glow effect |

Level is calculated dynamically from `totalFocusMinutes`.

### 6.3 Achievements

Predefined achievements unlocked automatically:

| ID | Name | Condition | Icon |
|----|------|-----------|------|
| first-sprout | First Sprout | Complete 1 session | `sprout` |
| green-thumb | Green Thumb | Grow 10 plants | `potted_plant` |
| streak-7 | Week Warrior | 7-day streak | `local_fire_department` |
| streak-30 | Monthly Master | 30-day streak | `auto_awesome` |
| deep-diver | Deep Diver | 1 session ≥ 60 min | `psychology` |
| collector | Collector | Own 1 of each rarity | `collections` |
| legendary | Legendary | Grow a legendary plant | `diamond` |

## 9. Storage & Persistence

### 9.1 IndexedDB Schema

```typescript
// Database: sproutdoro-db
// Version: 1

const db = await openDB('sproutdoro-db', 1, {
  upgrade(db) {
    // Settings store
    const settingsStore = db.createObjectStore('settings', { keyPath: 'id' });
    
    // Sessions store
    const sessionsStore = db.createObjectStore('sessions', { keyPath: 'id' });
    sessionsStore.createIndex('by-date', 'startTime');
    sessionsStore.createIndex('by-type', 'type');
    
    // Plants store
    const plantsStore = db.createObjectStore('plants', { keyPath: 'id' });
    plantsStore.createIndex('by-rarity', 'rarity');
    plantsStore.createIndex('by-level', 'level');
    
    // Insights store
    db.createObjectStore('insights', { keyPath: 'id' });
  }
});
```

### 9.2 Storage Operations

**Settings:**
- `getSettings(): Promise<Settings>` — returns defaults if not found
- `saveSettings(settings: Settings): Promise<void>` — immediate persist

**Sessions:**
- `createSession(session: Session): Promise<void>`
- `getSessions(startDate?: Date, endDate?: Date): Promise<Session[]>`
- `getTodaySessions(): Promise<Session[]>`
- `getSessionById(id: string): Promise<Session | undefined>`

**Plants:**
- `createPlant(plant: Plant): Promise<void>`
- `getAllPlants(): Promise<Plant[]>`
- `getPlantById(id: string): Promise<Plant | undefined>`
- `updatePlant(plant: Plant): Promise<void>`
- `getFeaturedPlant(): Promise<Plant | undefined>` — highest totalFocusMinutes

**Insights:**
- `getInsights(): Promise<Insights>` — computes from sessions/plants if not cached
- `updateInsights(insights: Insights): Promise<void>`

## 13. Error Handling

### 13.1 IndexedDB Errors

- **Open failure:** Show warning banner: "Storage unavailable. Sessions won't be saved."
- **Write failure:** Retry once, then log to console + toast notification
- **Quota exceeded:** Show prompt to clear old sessions

### 13.2 Audio Errors

- **Load failure:** Silently disable sounds, show "🔇" indicator
- **Play failure (user interaction):** Wait for user interaction, then retry

### 13.3 Timer Edge Cases

- **Tab inactive:** Use `visibilitychange` + `Date.now()` diff to correct drift
- **Browser close during session:** Save partial session on `beforeunload`
- **Negative time:** Clamp to 0, trigger completion

### 14.2 nginx.conf

```nginx
server {
  listen 80;
  server_name localhost;
  root /usr/share/nginx/html;
  index index.html;
  
  # Multi-page SPA fallback
  location / {
    try_files $uri $uri/ /index.html;
  }
  
  # Cache static assets
  location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf|eot|mp3)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
  }
  
  # Gzip compression

  gzip_types text/plain text/css application/json application/javascript text/xml;
}
```

## 17. Performance Considerations

1. **Image Optimization:** Use WebP format with JPG fallback, lazy-load garden images
2. **Code Splitting:** Each page gets its own JS chunk (Vite handles this)
3. **IndexedDB:** Batch read/writes where possible, index frequently queried fields
4. **Animations:** Use CSS transforms (GPU-accelerated), avoid layout-triggering properties
5. **Service Worker:** Cache-first strategy, stale-while-revalidate for dynamic data

1. **Contrast:** All text meets WCAG AA (4.5:1 for normal, 3:1 for large)

4. **Keyboard Navigation:** All controls operable via keyboard
