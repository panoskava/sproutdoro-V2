🎨 Sproutdoro — Complete App Design

All 4 screens, data flow, gamification, and PWA — presented section by section for your approval

📱 Screen 1: Focus Timer (index.html)

The Main Timer Experience

Layout Structure

  • SideNav (desktop): Glass-sage sidebar with user profile, nav links (Focus active), "Start Session" button
  • MobileNav (mobile): Glass-sage bottom bar with FAB center
  • Header: "Current Season: Spring Morning" (left), "Session Goal: Deep Focus (25m)" (right)
  • Center Stage:
    • Large circular SVG timer (320px mobile, 480px desktop)
    • Outer glass ring with glow
    • Progress track: primary stroke with round linecap
    • "Sun" dot (secondary_fixed) moving along track
    • Center: sprout image with soft radial mask + time display overlay
  • Controls: Reset, Pause/Play (gradient button), Skip
  • Stats Row: 4 stat cards (Session Sprout, Hydration, Today's Focus, Growth Stage)

Timer States

  • Idle: Timer at full duration, "Start" button
  • Running: Counting down, progress ring fills, "Pause" button
  • Paused: Frozen time, "Resume" button
  • Complete: 00:00, celebration animation, new seedling popup
  • Break: Short/Long break timer runs

⚙️ Screen 2: Settings (settings.html)

Configure Your Greenhouse

Bento Grid Layout

  • Timer Durations Card (span 8):
    • Work Session slider (1-60 min) → shows "25:00"
    • Short Break slider (1-15 min) → shows "05:00"
    • Long Break slider (5-45 min) → shows "15:00"
  • Appearance Card (span 4):
    • Light/Dark toggle (pill button group)
    • Soft description text
  • Ambience & Alerts Card (span 12):
    • 3 sound options: Soft Wind Chimes, Birdsong Morning, Rain on Leaves
    • Each has icon, name, description, radio-style selection
    • Volume slider (global)
  • Toggles (span 12):
    • Auto-start Breaks (ON/OFF)
    • Browser Notifications (ON/OFF)

Footer Actions

  • "Reset Defaults" button (text link)
  • "Save Changes" button (primary gradient)
  • Version text: "Sproutdoro v2.4.0 — Made with care"

Settings auto-save to IndexedDB immediately on change — no manual save needed for sliders, but Save button provides confirmation.

📊 Screen 3: Focus Insights (insights.html)

Your Productivity, Blossoming

Bento Grid

  • Daily Streak Card (span 4): Large number (14), "Days" label, fire icon background, encouragement text
  • Plants Grown Bar Chart (span 8): Weekly bar chart (Mon-Sun), plants per day, hover tooltips, Week/Month toggle
  • Focus Distribution Pie Chart (span 7): SVG donut chart, Deep Work/Reading/Planning breakdown, color-coded legend
  • Total Focus Hours (span 5): Large number (124), "Hours" label, monthly goal progress bar (82%)
  • Achievements Section (span 12): Badges (Oak of Focus, Morning Lavender, etc.), earned vs locked, plant image grid

Data Sources

  • Daily streak: consecutive days with ≥1 completed session
  • Bar chart: plants grown per day from session data
  • Pie chart: session categories (user can tag sessions)
  • Total hours: sum of all completed work session durations
  • Goal: user-defined monthly target (default: 40h)

🌱 Screen 4: My Garden (garden.html)

Your Cultivated Sanctuary

Layout

  • Header: "My Garden" title, description, stats (Total Plants: 24, Focus Hours: 158)
  • Featured Plant (span 2): Large card with full plant image, "Masterpiece" badge, name, story, date, Details button
  • Plant Grid: Masonry-style grid of plant cards
    • Plant image (aspect-square, rounded)
    • Rarity badge (bottom-right: Common/Rare/Legendary)
    • Plant name + date grown
    • Maturity progress bar (color-coded by level)
    • Level indicator: "Level 3 Maturity"
  • Empty Slot CTA: Dashed border card, "+" icon, "New Seedling" text

Gamification Details

  • Each completed session = 1 new seedling
  • Plant type randomly selected from unlocked pool
  • Rarity: Common 70%, Uncommon 20%, Rare 8%, Legendary 2%
  • Levels 1-5 based on cumulative focus time with that plant
  • Masterpiece = plant with highest total focus time
  • FAB: "New Sprout" button (quick-start session)

💾 Data Architecture

IndexedDB Stores

  • settings: timer durations, theme, sound, volume, toggles
  • sessions: start/end time, duration, type, plantId, category
  • plants: id, type, rarity, level, plantedAt, totalFocusMinutes
  • insights: streak data, daily/weekly stats, achievements

Default Settings

  • Work: 25 min | Short: 5 min | Long: 15 min
  • Theme: Light | Sound: Wind Chimes
  • Volume: 50% | Auto-start: ON
  • Notifications: ON

🚀 PWA & Deployment

  • Manifest: App icons, theme colors, display: standalone
  • Service Worker: Precaches all pages + assets, offline functionality
  • Icons: 192x192 and 512x512 plant-themed icons
  • Docker: Multi-stage build → nginx:alpine (~25MB)
  • Hosting: Any static host or Docker container
