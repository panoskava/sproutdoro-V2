Recommended Technology Stack

Lightweight, PWA-ready, Docker-friendly

A

Vite + Vanilla JS/TS

My recommendation. Modern dev experience (modules, hot reload) but compiles to zero-overhead static files. No framework runtime — just pure JS.

  • ✅ Ultra-lightweight output
  • ✅ PWA via Vite PWA plugin (auto-generates service worker + manifest)
  • ✅ IndexedDB (via idb package) for local data storage
  • ✅ Docker: serve static files with nginx (single nginx:alpine image)
  • ✅ All your existing HTML/Tailwind mockups work as-is
B

Svelte + Vite

A compiler-based framework that produces tiny, efficient JS. Great for reactive UI but adds a small build step.

  • ✅ Very small bundle size (smaller than React/Vue)
  • ✅ Built-in reactive state management
  • ❌ Slightly more complex than vanilla
  • ⚠️ Would require converting your HTML mockups to .svelte components
C

Plain HTML/CSS/JS (No Build Tool)

Your mockups are already in this format. Zero tooling, but manual module management.

  • ✅ No build step at all
  • ✅ Works exactly like your mockups
  • ❌ Harder to manage multiple screens/components
  • ❌ Manual PWA setup (service worker, caching)
  • ❌ No hot reload during development

Why I recommend Option A

  • Your mockups already use Tailwind CDN — Vite can bundle Tailwind properly
  • PWA plugin auto-generates service worker, icons, manifest
  • IndexedDB wrapper makes storing sessions/insights trivial
  • Single Dockerfile with nginx:alpine — ~25MB image
  • You can write vanilla JS but get module imports, TypeScript if desired

Trade-offs

  • Small build step (but Vite is very fast)
  • Need to convert from CDN Tailwind to npm install tailwindcss
