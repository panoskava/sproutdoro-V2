Sproutdoro — Complete Design

All screens, data flow, and PWA architecture

📋 Summary of Decisions So Far

  • Tech: Vite + TypeScript, multi-page HTML, Tailwind CSS, IndexedDB
  • Hosting: Docker with nginx:alpine (~25MB image)
  • App Type: Multi-page PWA (4 separate HTML files)
  • Garden: Session-completion → random seedling → level-up with focus time

🗂️ Page Breakdown

1. index.html — Focus Timer

  • Circular SVG progress ring (primary stroke)
  • "Sun" dot moving along track (secondary_fixed)
  • Center: sprout image + time display
  • Controls: Pause/Play, Reset, Skip
  • Session stats below: plant type, hydration, focus hours, growth stage
  • SideNav + MobileNav with "Focus" active

2. settings.html — Config

  • Bento grid layout
  • Timer sliders: Work (1-60min), Short Break (1-15), Long Break (5-45)
  • Theme toggle: Light/Dark
  • Sound picker: Wind Chimes, Birdsong, Rain
  • Volume slider
  • Toggles: Auto-start breaks, Browser notifications
  • Save / Reset buttons

3. insights.html — Focus Insights

  • Daily streak card (large number, fire icon)
  • Bar chart: Plants grown per day this week
  • Pie chart: Focus distribution by category
  • Total focus hours + monthly goal progress
  • Achievement badges + plant showcase

4. garden.html — My Garden

  • Featured plant (largest card with image)
  • Grid of all plants with images, names, dates
  • Progress bars showing maturity level
  • Rarity badges (Common, Rare, Legendary)
  • Empty slot CTA: "Start a session to plant"
  • Stats: Total plants, total focus hours

⚙️ Shared Components (TypeScript)

SideNav.ts — Desktop nav, highlights active page
MobileNav.ts — Bottom nav (mobile only)
CircularProgress.ts — SVG timer ring with animated stroke-dashoffset
StatCard.ts — Glass-morphism stat cards (icon + label + value)
PlantCard.ts — Garden grid card (image, name, date, level bar)
RangeSlider.ts — Styled range input for settings
ToggleSwitch.ts — Custom toggle button
SoundCard.ts — Selectable sound option card

🔄 Timer Logic & State Flow

Session Lifecycle
  1. User clicks "Start Session" → Timer begins countdown from Settings.workDuration
  2. Timer ticks every second → Updates SVG progress ring, time display
  3. User pauses → Timer stops, "Resume" button shown
  4. Timer reaches 00:00 →
    • Play completion sound
    • Save session to IndexedDB
    • Generate new seedling (random type)
    • Show completion modal/animation
    • Auto-start break if setting enabled
  5. Break timer runs → Same mechanics, shorter duration
  6. After 4 work sessions → Long break instead of short

💾 Data Storage (IndexedDB)

Stores

  • settings: workDuration, breakDuration, longBreakDuration, theme, sound, volume, autoStart, notifications
  • sessions: id, startTime, endTime, duration, type (work/break), plantId
  • plants: id, type, rarity, level, plantedAt, totalFocusMinutes, sessionIds, isMasterpiece
  • insights: dailyStats, weeklyStats, achievements, streakData

Default Settings

  • Work: 25 min
  • Short break: 5 min
  • Long break: 15 min
  • Theme: Light
  • Sound: Soft Wind Chimes
  • Volume: 50%
  • Auto-start breaks: ON
  • Notifications: ON

📱 PWA Configuration

  • manifest.json: App name, icons, theme color, display: standalone
  • Service Worker: Precaches all 4 HTML files + assets, serves offline
  • Icons: 192x192, 512x512 (sprout/plant themed)
  • Splash screen: Branded loading screen on mobile

🎨 Design System Compliance

  • Colors: Exact hex values from DESIGN.md (no pure black, warm tones)
  • No hard borders: Color-blocking and background shifts only
  • Typography: Plus Jakarta Sans (headlines/labels) + Be Vietnam Pro (body)
  • Glassmorphism: Frosted sage at 80% opacity, 24px blur for overlays
  • Animations: Cubic Bezier (0.34, 1.56, 0.64, 1) for bouncy organic feel
  • Responsive: Mobile-first with desktop side nav
