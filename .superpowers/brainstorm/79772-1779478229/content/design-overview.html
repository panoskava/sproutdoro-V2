Key Design Decisions

  • Hash routing (#focus, #settings, #insights, #garden) — no server config needed, works with static file hosting
  • Centralized StateManager — pub/sub pattern so any component can react to timer changes, settings updates, etc.
  • IndexedDB via idb package — persists sessions, plants, settings locally on device
  • Vite PWA Plugin — auto-generates service worker for offline use, installable on mobile
  • CSS-first animations — organic, bouncy feel matching design system (Cubic Bezier 0.34, 1.56, 0.64, 1)
